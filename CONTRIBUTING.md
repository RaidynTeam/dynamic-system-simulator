# Katkı süreci

Kendi rol belgenizi `docs/team/` altında okuyun. `main` üzerinden
`feat/<scope>-m1` benzeri bir branch açın; küçük, tek amaçlı commitler hazırlayın.

Commit: `<type>(<scope>): <English imperative description>`.
Örnek: `feat(numerical): implement euler integration`.
Türler: feat, fix, test, docs, refactor, chore, ci.

PR'da amaç, değişiklik, çalıştırılan test ve sonuç, eksikler ve varsa ilgili Issue belirtilir.
En az bir başka ekip üyesi incelemeli; testler geçmeden birleştirilmemelidir.
Bu kuralların GitHub üzerinde teknik olarak etkinleştirildiği varsayılmaz.
